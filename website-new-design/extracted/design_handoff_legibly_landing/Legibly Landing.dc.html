Unreadable design is now a legal risk.

The European Accessibility Act has applied since June 2025, and ADA lawsuits keep climbing. The most common failure in every audit is contrast — and contrast is decided in the design file, months before an engineer can be blamed for it. Legibly moves the fix back to where the mistake was made.

How it works

Scan. Fix. Verify.

  1. 01

    Scan

    Select frames or a whole page. Legibly resolves the real background behind every layer — fill stacks, opacity, gradients, overlapping siblings.

  2. 02

    Fix

    One click swaps every failing value for the nearest passing color in your own token set. Nothing off-system is ever invented, and one undo reverses it.

  3. 03

    Verify

    The same function that flagged the violation re-checks the fix and reports the new ratio. If nothing can pass, it says so instead of guessing.

Three verdicts, no guessing

Zero false positives is a design constraint here, not a marketing line.

Violation The math is certain, so a fix is offered. Contrast is arithmetic and target size is geometry — neither needs an opinion.
Needs review Gradients, images and blend modes that cannot be measured safely get flagged for a human instead of guessed at.
Not checked The report lists every criterion Legibly did not evaluate, so silence never reads as a pass.

Flagging is the easy half

A typical checker

Flags dozens of issues, many of them false positives from gradients and overlaps it cannot read. The fixing is still on you, one layer at a time.

Legibly

Flags only what is provably wrong, then fixes the whole page in one click with your tokens and re-verifies every change before it lands. One Cmd-Z undoes it all.

Coverage

Nine checks, one honest report

Every one of them decided by math, not opinion — and each one named in the report whether it passed, failed or was left alone.

  1. 01

    Text contrast SC 1.4.3

    Measured against the background the text actually sits on — composited through fill stacks, opacity and gradients.

  2. 02

    Line spacing SC 1.4.12

    Line height under 1.5× the type size, where copy stops holding together at reading distance.

  3. 03

    Target size SC 2.5.8 · 2.5.5

    Controls under 24 by 24 — or 44 in mobile mode — measured as geometry, spacing exception included.

  4. 04

    Icon and border contrast SC 1.4.11

    The parts you have to see in order to act: icon strokes, input edges, control borders.

  5. 05

    Image alt text SC 1.1.1

    A presence check on every image, with optional drafts written under your own API key.

  6. 06

    Color-only links SC 1.4.1

    Links that differ from the body copy by hue alone, with no underline to carry them.

  7. 07

    Clipped text SC 1.4.10

    Copy that overflows its frame and is simply never read by anyone.

  8. 08

    Field labels SC 2.4.6

    Inputs carrying only a placeholder where a visible label is the requirement.

  9. 09

    Focus states SC 2.4.7

    Components given a hover state and no keyboard focus state to match it.

  10. +

    And checks 01 and 04 run again on every theme you ship, not only the one on screen. Dark mode is where fixed contrast quietly breaks.

Questions, answered

Does it really fix, or just report? ▾

It fixes. Every violation with certain math gets a repaired value written back to the canvas from your token set, then re-measured. A single undo reverses a whole page.

Will it invent colors outside my design system? ▾

No. Strict mode restricts every repair to your published tokens; when nothing in the set can pass, Legibly reports the gap rather than inventing a shade.

What happens with gradients and image backgrounds? ▾

They are measured where the math is safe and marked “needs review” where it is not. You get the range and the worst case, never a confident number that isn't one.

Is my file private? ▾

Yes. Nothing leaves your machine except the alt-text drafts you explicitly request, and those go directly to Anthropic under your own API key.

Which criteria do you not check? ▾

Anything that needs runtime behaviour or human judgement — focus order, keyboard traps, semantics, motion. The report names each one so silence is never mistaken for a pass.
